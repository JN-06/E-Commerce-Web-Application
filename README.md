Project Summary
Developed a full-stack collectible toy e-commerce web application using Vue.js, Vite, Node.js, Express, MongoDB, and Mongoose. Implemented responsive user interfaces, product browsing, collections, authentication with JWT, shopping cart, wishlist, checkout, order management, and an admin dashboard with CRUD functionality. Integrated Axios for frontend-backend communication and OCR-based payment verification to support a realistic end-to-end e-commerce workflow.
